# 🧪 OpoLab · by Oposalud

Repositorio de recursos interactivos para la preparación de oposiciones sanitarias.

## Publicación con GitHub Pages

1. Subir el contenido de esta carpeta a la raíz del repositorio.
2. Abrir **Settings → Pages**.
3. En **Source**, elegir **Deploy from a branch**.
4. Seleccionar la rama **main** y la carpeta **/(root)**.
5. Pulsar **Save**.

El primer juego quedará disponible en:

`https://USUARIO.github.io/opolab/juegos/opodetective-dermatologia/`
